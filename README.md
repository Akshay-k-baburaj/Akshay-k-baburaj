### 🏦 Secure Digital Banking Platform

*Problem: moving money between accounts safely, with the right checks at every step.*

A Spring Boot banking backend with multi-account management, beneficiary management, and real-time fund transfers. Transfers are protected by JWT authentication and transaction-PIN verification, with searchable transaction history.

### 💸 Expense Splitter 

*Problem: tracking who owes whom in a group without messy spreadsheets.*

A layered REST API for group expense tracking. Includes Flyway migrations, a soft-delete strategy that anonymizes unique fields to avoid constraint collisions on re-registration, and a composite-key model (`@EmbeddedId` + `@MapsId`) for group membership. Next up: member management and split calculation.

`Java 21` `Spring Boot 3` `PostgreSQL` `JPA` `Flyway` `MapStruct`

[Repository →](https://github.com/Akshay-k-baburaj/expense-splitter)

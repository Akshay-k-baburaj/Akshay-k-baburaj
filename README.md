## 🚀 Featured Projects

### 💸 Enterprise-Grade Expense Splitter API &nbsp;`🚧 In Progress`
> A layered REST API for group expense tracking, built with production-style practices.

- **Stack:** Java 21 · Spring Boot 3 · PostgreSQL · Spring Data JPA · Flyway · MapStruct · Jakarta Validation
- Completed the **User domain**: CRUD, validation, and global exception handling
- Designed a **soft-delete strategy** that anonymizes unique fields to avoid unique-constraint collisions on re-registration
- Modeled group members with a **composite key** (`@EmbeddedId` + `@MapsId`) to track join time
- **Up next:** member management and split calculation

[![Repo](https://img.shields.io/badge/View_Repo-181717?style=for-the-badge&logo=github)](https://github.com/Akshay-k-baburaj/expense-splitter-api)

### 🏦 Secure Digital Banking Platform
> A banking backend with multi-account support and real-time fund transfers.

- **Stack:** Spring Boot · PostgreSQL · JWT · Spring Security
- Multi-account and **beneficiary management**
- **Real-time fund transfers** with JWT authentication and **transaction-PIN verification**
- Transactional deposits, withdrawals, and transfers, plus **searchable transaction history**

[![Repo](https://img.shields.io/badge/View_Repo-181717?style=for-the-badge&logo=github)](https://github.com/Akshay-k-baburaj/digital-banking-platform)
